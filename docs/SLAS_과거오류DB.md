# SLAS 과거 오류 DB

이전 프로젝트 또는 유사 시스템에서 실제로 발생한 오류를 기록한 데이터베이스이다.

---

### SLAS-HDB-001

| 항목 | 내용 |
|---|---|
| **오류** | 카메라 차단 전환 시 이전에 표시되던 제한속도가 계속 강조 표시됨 |
| **심각도** | Critical |
| **발생 상황** | 고속도로 80km/h 구간 정상 주행 중, 대형 차량이 전방 카메라를 가려 카메라 상태가 BLOCKED로 전환됨 |
| **증상** | 카메라가 차단되었음에도 이전에 표시되던 제한속도(80km/h)가 AMBER 색상으로 계속 표시되었고, ASSIST 모드에서는 설정속도 변경 안내까지 출력됨. 운전자가 현재 유효한 제한속도로 오인할 수 있는 상황이었음 |
| **근본 원인** | 기능 제한 상태로 전환할 때 이전 표시값(previousDisplayedLimit)을 초기화하지 않고 현재 적용 제한속도로 재사용하는 로직 오류 |

### SLAS-HDB-002

| 항목 | 내용 |
|---|---|
| **오류** | 카메라와 내비게이션 제한속도가 동일할 때 출처가 NONE으로 표시됨 |
| **심각도** | Minor |
| **발생 상황** | 도심 40km/h 구간에서 카메라와 내비게이션이 동일한 제한속도(40km/h)를 인식하는 상황이 지속됨 |
| **증상** | 클러스터에 제한속도 40km/h는 정상 표시되었으나, 제한속도 출처가 CAMERA 또는 NAVIGATION이 아닌 NONE으로 표시됨. 서비스 진단 시 데이터 출처 추적이 불가능하여 원인 분석이 지연됨 |
| **근본 원인** | 두 소스의 값이 일치할 때 우선순위 판단을 생략하고 출처를 미지정으로 처리하는 분기 오류 |

### SLAS-HDB-003

| 항목 | 내용 |
|---|---|
| **오류** | 고속도로 분기 구간에서 출구 도로 표지판을 본선 제한속도로 오인함 |
| **심각도** | Critical |
| **발생 상황** | 고속도로 분기 구간에서 본선 80km/h와 출구 60km/h 표지판이 동시에 전방 카메라에 인식됨. 차량은 본선을 계속 주행 중이었음 |
| **증상** | 본선 주행 중임에도 클러스터에 60km/h가 표시되었고, 70km/h 주행 시 불필요한 과속 경고가 발생함. 운전자에게 잘못된 감속 유도가 이루어짐 |
| **근본 원인** | 복수 표지판 감지 시 현재 주행 도로(본선/출구)를 구분하지 않고 낮은 제한속도 값을 선택하는 로직 오류 |

### SLAS-HDB-004

| 항목 | 내용 |
|---|---|
| **오류** | 최저속도 표지판을 제한속도 표지판으로 오인함 |
| **심각도** | Major |
| **발생 상황** | 자동차 전용도로에서 최저속도 50km/h 원형 표지판이 인식됨. 해당 구간에 내비게이션 제한속도 정보는 없었음 |
| **증상** | 최저속도 50km/h가 제한속도로 표시되었고, 60km/h 주행 시 불필요한 과속 경고가 발생함. 운전자가 감속하여 후방 차량과의 안전거리 문제가 발생함 |
| **근본 원인** | 표지판 타입(SPEED_LIMIT, MIN_SPEED 등) 필터링 없이 카메라 인식 속도값을 그대로 제한속도로 적용하는 로직 오류 |

### SLAS-HDB-005

| 항목 | 내용 |
|---|---|
| **오류** | 시동 직후 카메라 초기화 완료 전에 과속 경고가 발생함 |
| **심각도** | Major |
| **발생 상황** | 고속도로 휴게소에서 시동을 건 후 본선에 합류하는 과정에서, 시동 후 약 10초 시점에 차량 속도가 80km/h에 도달함 |
| **증상** | 카메라 초기화가 완료되지 않은 상태에서 이전 주행의 제한속도 정보를 기반으로 과속 경고가 발생함. 운전자에게 시스템 신뢰성 저하를 야기함 |
| **근본 원인** | 시스템 초기화 상태(INITIALIZING) 확인보다 과속 경고 판정 로직이 먼저 실행되는 우선순위 처리 오류 |

### SLAS-HDB-006

| 항목 | 내용 |
|---|---|
| **오류** | SLAS OFF 상태에서 속도 상태 색상 또는 과속 경고가 남아 있음 |
| **심각도** | Major |
| **발생 상황** | 주행 중 운전자가 HMI에서 SLAS 기능을 OFF로 전환함. 전환 직후 차량 속도가 이전 제한속도를 초과하는 상태였음 |
| **증상** | SLAS 기능이 OFF임에도 클러스터에 과속 경고가 표시되고 SLAS 보조 표시가 RED로 유지됨. 운전자가 기능 OFF 여부를 혼동하여 반복적으로 OFF를 시도함 |
| **근본 원인** | OFF 모드 전환 시 과속 경고 판정 로직이 모드 상태를 확인하지 않고 속도 비교를 수행하는 분기 오류 |

---

### SLAS-HDB-007

| 항목 | 내용 |
|---|---|
| **오류** | 기능 제한 상태에서 설정속도 변경 안내가 출력됨 |
| **심각도** | Major |
| **발생 상황** | ASSIST 모드로 주행 중 터널 진입으로 카메라가 BLOCKED 상태로 전환됨. ACC 설정속도(60km/h)가 이전 적용 제한속도(80km/h)와 불일치하는 상태였음 |
| **증상** | 카메라 BLOCKED로 기능이 제한된 상태임에도 클러스터에 "설정속도 UP" 안내가 표시됨. 신뢰할 수 없는 제한속도 정보에 기반한 안내가 운전자를 오도할 수 있는 상황이었음 |
| **근본 원인** | 기능 제한 상태 확인과 ASSIST 모드 안내 로직 간의 우선순위 처리 오류. 기능 제한 시 안내를 먼저 억제해야 하나, 안내 로직이 독립적으로 실행됨 |

### SLAS-HDB-008

| 항목 | 내용 |
|---|---|
| **오류** | 내비게이션 제한속도를 사용하면서 출처를 카메라로 표시함 |
| **심각도** | Major |
| **발생 상황** | 시외 도로에서 표지판 훼손으로 카메라 인식 신뢰도가 낮아(LOW_CONFIDENCE) 내비게이션 제한속도(60km/h)로 전환 적용된 상황 |
| **증상** | 클러스터에 표시된 제한속도 60km/h는 내비게이션 값이었으나, 출처가 CAMERA로 표시됨. 서비스 센터 진단 시 카메라 인식 오류로 잘못 분류되어 표지판 교체 요청이 불필요하게 발생함 |
| **근본 원인** | 제한속도 소스 전환(카메라→내비게이션) 시 적용 값은 정상 변경되었으나, 출처 표시값의 동기화가 누락됨 |

### SLAS-HDB-009

| 항목 | 내용 |
|---|---|
| **오류** | 터널 구간 진입 시 제한속도가 표시되지 않음 |
| **심각도** | Minor |
| **발생 상황** | 도심 터널(제한속도 60km/h) 진입 시, 터널 입구에서 전방 카메라가 제한속도 표지판을 정상 인식한 직후 터널 내부로 진입함 |
| **증상** | 터널 구간에 진입하자 클러스터의 제한속도 표시가 60km/h에서 "---"로 전환됨. 터널 내 주행 중 제한속도 정보가 없는 상태가 지속됨 |
| **근본 원인** | 도로 컨텍스트가 TUNNEL로 전환될 때 카메라 인식 정보를 초기화하는 불필요한 로직이 존재하여, 유효한 제한속도 정보가 소실됨 |
